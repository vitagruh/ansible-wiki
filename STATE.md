## Проверка сборки

MkDocs Material установлен в `py -3.15` (Python 3.15). PyYAML 6.0.3 не имеет wheel для cp315, поэтому установлены pure-Python файлы пакета и метаданные из официального wheel; расширение `_yaml` не используется. Это влияет только на скорость парсинга YAML, не на результат сборки.

| Команда | Назначение |
|---|---|
| `py -3.15 -m mkdocs serve` | локальный предпросмотр |
| `py -3.15 -m mkdocs build --strict` | строгая сборка в `site/` |
| `py -3.15 tools/verify_docs.py` | структурная проверка и локальные ссылки |
| `py -3.15 tools/build_bookstack.py` | сборка `dist/ansible-wiki-bookstack.zip` |

## Правила поддержки

- Не переписывать готовые страницы без причины; исправления противоречий фиксировать здесь и в `CHANGELOG.md`.
- Новые страницы добавлять одновременно в `mkdocs.yml` и в `CHAPTERS` в `tools/build_bookstack.py`.
- После изменений запускать `verify_docs.py`, `mkdocs build --strict` и `build_bookstack.py`.
- Не добавлять ссылки на несуществующие страницы: проверка считает их ошибкой.
